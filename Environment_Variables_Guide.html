2. Frontend Environment Variables (frontend/.env)

Set this variable on Netlify / Vercel Environment Variables:

# ===== API Gateway Endpoint =====
VITE_API_URL=https://your-backend-app.onrender.com/api

3. Instructions for Contributor

  1. Backend Hosting (Render/Railway): Create a new Node.js web service linked to the backend/ folder. Paste all Backend variables into the Environment section. Set start command to node server.js.
  2. Frontend Hosting (Netlify/Vercel): Create a new site linked to the frontend/ folder. Set build command to npm run build and publish directory to dist. Add VITE_API_URL to Environment Variables.
